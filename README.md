## Approach

Every machine gets a full writeup regardless of whether I solved it 
independently or needed hints. The methodology stays consistent throughout:

- Reconnaissance and enumeration first, always
- Manual testing before automated tools
- Document what failed and why, not just what worked
- Map findings to MITRE ATT&CK or OWASP where relevant
